## 二、任务 1 · 评测集 Schema 规范

`config/physics_eval_schema.json`（v1.0.0）已建立，8 字段契约与题量配额如下：

| 字段 | 类型 | 约束 |
|---|---|---|
| `eval_id` | string | `^EVAL_P[0-9]{3}$`，**取值恒等于 `"EVAL_" + concept_id`** |
| `concept_id` | string | `^P[0-9]{3}$`，必须存在于阶段二产出中 |
| `question_type` | string | 枚举 3 类，配额 20/20/10 |
| `question` | string | ≥ 8 字 |
| `options` | array&lt;string&gt; | **恰好 4 项**，非空、互不重复、无「以上都对」类元选项 |
| `correct_option` | string | 枚举 A/B/C/D，与 options 下标一一对应 |
| `explanation` | string | ≥ 20 字 |
| `target_hallucination_point` | string | ≥ 4 字（辨析题、公式题也必填） |

**两处需要你确认的实现选择：**

1. **`eval_id` 采用 `EVAL_P001` 这种形式**（与你给的示例一致），靠 `concept_id == "P###"` 保证唯一。为此我把 50 道题分配到 **50 个互不重复的概念**上（100 条里取 50 条），顺带把评测集的概念覆盖面拉满。
2. **你写的是"多选题"，但 Schema 的 `correct_option` 是单个字母**，所以我实现为**四选一单选题**（4 个选项、唯一正确答案），"多"体现在"四选一"上。若你要的是"多选多正确"（答案形如 `["A","C"]`），需要改 Schema 字段类型，告诉我我来改。
3. `options` 存的是**纯选项文本，不带 `A.` 前缀**（`correct_option` 已承载字母）。这样程序化映射更干净；若你的下游工具需要 `"A. xxx"` 形式，加一个 `--option-prefix` 开关即可。

## 三、任务 2 · 衍生脚本与 50 题生成

### 3.1 脚本

`scripts/generate_physics_eval.py`，复用 `src/common.py` 基础设施与阶段二的 Ollama 调用/JSON 抽取实现，不另起一套。

**核心设计：标识字段不由模型决定。** `eval_id` / `concept_id` / `question_type` 由脚本的**确定性蓝图**给出，模型只负责组织题干、选项、答案、解析。出题蓝图（`TRAP_SPECS` / `FORMULA_SPECS` / `DISTINCTION_SPECS`）把每道题锚定的概念、对比概念、错误前提都写死，保证覆盖面可控、可复现——这是阶段二"ID 漂移"教训的直接延续。

**幻觉陷阱题的素材来源是阶段二的实测缺陷。** 10 道陷阱题的错误前提全部取自阶段二 `graph_quality` 检出的模型易错边，例如：

| 陷阱题 | 植入的错误前提 | 来源 |
|---|---|---|
| EVAL_P005 | 动量属于能量 | 阶段二 `动量.parent = 能量` |
| EVAL_P008 | 功率是一种能量 | 阶段二 `功率.parent = 能量` |
| EVAL_P059 | 温度是一种能量 | 阶段二 `温度.parent = 能量` |
| EVAL_P066 | 熵是热力学第二定律的下位概念 | 阶段二 `熵.parent = 热力学第二定律` |
| EVAL_P010 | 加速度是运动学的一个分支学科 | 阶段二分类名当上位 |
| EVAL_P080 | 欧姆是电阻的下位概念 | 阶段二 `电阻.child = [欧姆]` |
| EVAL_P004 | 万有引力定律是一种力 | 阶段二 `万有引力定律.parent = 力` |

**出题后加了一道盲测自洽校验**：把题面单独喂回模型（不给答案），看它是否选到答案键。这是质量信号，不是正确率保证——幻觉陷阱题**期望**模型答错，那正是该题的测出能力所在。

## 四、任务 3 · 抽样展示（3 道，随机种子 20261014，已排除确认缺陷题）

### ① 概念辨析题 · EVAL_P044 `P044 频率`

> **题干**：在描述一个振动过程时，频率与周期的关系是怎样的？
>
> A. 频率越高，周期越长
> B. 频率与周期互为倒数
> C. 频率表示振动的幅度大小
> D. 周期表示单位时间内振动的次数
>
> **正确答案：B**
>
> **解析**：正确选项是频率与周期互为倒数。主要干扰项错误在于混淆了频率和周期的定义——频率表示单位时间内完成的振动次数，而周期则是完成一次振动所需的时间。
>
> **target_hallucination_point**：频率和周期的关系容易混淆

### ② 公式应用与量纲题 · EVAL_P068 `P068 理想气体状态方程`

> **题干**：一定量的理想气体在等温过程中，如果体积增大 1 倍，则压力会如何变化？
>
> A. 增大 1 倍
> B. 减小到原来的一半
> C. 保持不变
> D. 增大到原来的 2 倍
>
> **正确答案：B**
>
> **解析**：根据理想气体状态方程 PV = nRT，在等温过程中 T 和 n 都保持不变，所以 P 与 V 成反比。选项 A 和 D 记错了正比关系，选项 C 混淆了等温过程与其它过程的区别。
>
> **target_hallucination_point**：模型对理想气体定律中不同过程的区分不够清晰

### ③ AI 幻觉陷阱题 · EVAL_P008 `P008 功率`

> **题干**：在一次物理复习课上，小明提出了一个观点：'功率是一种能量'。请问下列说法中，哪一个是正确的？
>
> A. 功率是单位时间内完成的功，是描述能量转化快慢的物理量
> B. 功率和能量一样，都可以用焦耳作为单位
> C. 功率和能量一样，都是描述物体做功能力的大小
> D. 功率和能量一样，都表示物体做功的能力
>
> **正确答案：A**
>
> **解析**：正确答案指出功率和能量是不同概念，功率描述的是能量转化的速度，而非能量本身。其他选项都顺从了错误前提，混淆了二者关系。
>
> **target_hallucination_point**：把种属关系误判为同一类关系

三道题的构造质量都达标：陷阱题的三个干扰项（"都可以用焦耳作单位""都是描述做功能力"）确实是语言模型容易接受的表述，正确答案需要模型主动否定该错误前提——这正是我们要测的能力。

## 五、核心发现：答案键不可直接使用（这部分请重点看）

**Schema 100% 通过，不等于题目 100% 可用。** 我对盲测不一致的题目做了逐题人工验算，结论如下。

### 5.1 盲测自洽 ≠ 物理正确

`--repair` 把自洽率从 74% 提到 86%，但**这个数字有欺骗性**。逐个验算重制的 6 题：

| eval_id | 重制后验算结论 |
|---|---|
| EVAL_P007 功 | ✅ 正确（W = Fd·cosθ = 10×8×0.5 = 20 J） |
| EVAL_P053 压强 | ✅ 正确（p = F/S = 200/0.1 = 2000 Pa） |
| EVAL_P056 浮力 | ✅ 正确（V = F/(ρg) = 40/10000 = 0.004 m³） |
| EVAL_P082 电功率 | ⚠️ 数值对（P = I²R = 4×10 = 40 W），但题干单位误写"焦耳" |
| **EVAL_P021 角动量** | ❌ **仍然错误**：I = ½mr² = 0.25，L = Iω = **1.25 kg·m²/s**，而四个选项（6.28/15.7/3.14/9.42）**都不含正确值** |
| **EVAL_P089 光的折射** | ❌ **仍然错误**：n水·sin30° = 0.665 → r ≈ **41.7°**，选项最大只有 35°；解析算出 37° 却选了 27° |

**重制只是把"不一致的错误"变成了"一致的错误"。** 模型可以稳定地、自信地给出错误的答案键——单靠自洽校验无法发现。这个结论必须写进方法论。

### 5.2 已确认有害缺陷的 9 道（须人工修正后才能使用）

| eval_id | 缺陷 | 人工验算结论 |
|---|---|---|
| EVAL_P021 角动量 | 正确答案不在选项内 | 正确值 1.25，选项全是错值 |
| EVAL_P089 光的折射 | 答案键与解析矛盾 | 正确值 ≈41.7°，解析算出 37° 却选 27° |
| EVAL_P061 比热容 | 正确答案不在选项内 | ΔT = 42000/(385×2) = 54.5°C → 终温 74.5°C，选项只有 25/30/35/40 |
| EVAL_P029 胡克定律 | 题干与选项冲突 | 问"弹力**大小**"却给带负号选项（-1 N 不构成"大小"） |
| EVAL_P033 弹力 | 答案键存疑 | A 是教科书标准表述；B 称"摩擦力由粗糙程度决定"漏掉正压力 |
| EVAL_P066 熵 | 双正确项 | B 与 D 均成立 |
| EVAL_P075 电场 | 双正确项 | 问"哪个是标量"，B（电势差）与 D（电势）**都是标量** |
| EVAL_P078 电容 | 双正确项 | C"电容属于电学中的一个具体概念"本身成立 |
| EVAL_P088 光的反射 | 双正确项 | A（描述反射）、B（描述折射）均为正确表述 |

**缺陷类型归纳**：① 答案键与解析自相矛盾；② 正确答案不在选项内；③ 两个选项都成立（破坏单选唯一性）；④ 题干条件不足或与选项冲突。

### 5.3 缺陷率估计

- **13/50 = 26%** 未通过任何自动校验，或经人工确认有缺陷；
- **9/50 = 18%** 已逐题验算确认存在有害缺陷；
- **剩余 37 题未逐题验算**。鉴于 EVAL_P021 / EVAL_P089 已证明「自洽通过 ≠ 正确」，这 37 题中很可能仍有同类缺陷，**真实缺陷率大概率高于 18%**。

### 5.4 根因

这与阶段二「关系边双向闭合率仅 48.4%」是**同一类问题的延续**：7B 模型能流畅生成**语言形式正确**的物理文本，但**不能在多步数值推理与概念边界判定上保持自洽**。阶段二表现为关系边错乱，阶段三表现为答案键错乱。

## 七、对下一阶段的建议

1. **答案键必须换人来出。** 建议双轨制：模型只负责**生成题干与选项**（它做得不错），正确答案**由人工或规则/符号计算引擎裁定**。特别是公式题——用 sympy 之类的符号计算引擎自动验算数值，能把 5.2 节那类"答案不在选项内"的缺陷挡在生成阶段。这是投入产出比最高的一步。

2. **评测集启用前，先冻结这 9 道题的修正值。** 其余 41 道至少按 20% 抽检——因为已证明自洽通过不代表正确。

3. **幻觉陷阱题的有效性要拿别的模型来测。** 现在这 10 道题是"模型出题、模型盲答"，同一模型的盲答只是下限参考，不构成难度证据。真正有价值的是拿它们去跑**其他模型**（GPT/Claude/其他开源模型），看谁掉坑——那才是 benchmark 的意义。

4. **扩题前先把答案键管道修好。** 50 题规模下人工能补；500 题时人工成本会失控，必须先有自动验算环节。

5. 吞吐可线性外推：**4.42 秒/题（含盲测）**，500 条约 37 分钟。
